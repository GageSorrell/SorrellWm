# `@sorrell/build-windows`

**Purpose.**&ensp;A build tool for NodeJS packages that expose the [Windows API](https://learn.microsoft.com/en-us/windows/win32/apiindex/windows-api-list) via the [node-addon-api](https://github.com/nodejs/node-addon-api/).
