# Electron Reactive Event Extension for VS Code

This extension for VS Code accompanies Electron apps built with [`electron-reactive-event`](https://github.com/GageSorrell/ElectronReactiveEvent).
It generates the module augmentation code for you upon saving relevant modules in your project.
Under the hood, it runs the same logic provided by the [`electron-reactive-event-cli`](https://github.com/GageSorrell/ElectronReactiveEventCli).

For more details about [`electron-reactive-event`, please see the GitHub repo here](https://github.com/GageSorrell/ElectronReactiveEvent).
