# Reactive Event Extension for VS Code

This extension for VS Code accompanies Electron apps built with [`reactive-event`](https://github.com/GageSorrell/ReactiveEvent).
It generates the module augmentation code for you upon saving relevant modules in your project.
Under the hood, it runs the same logic provided by the [`reactive-event-cli`](https://github.com/GageSorrell/ReactiveEventCli).

For more details about [`reactive-event`, please see the GitHub repo here](https://github.com/GageSorrell/ReactiveEvent).
