# `@sorrell/codehike`

**Purpose.**&ensp;This package provides a `<CodePresentation />` component and helpers to create animations that showcase and explain code snippets.

## Setup

It is recommended to create a standalone package for your animations.
For example, if these animations will be used in a website, which is a NodeJS package, then from the root of that package,

```bash
mkdir Animations
cd Animations
npm init -y --prefix .
```

Then, add the necessary dependencies,

```bash
npm install --save-dev typescript@^6.0.0 react@^18.0.0 react-dom^18.0.0 @types/react^18.0.0
npm install --save-dev --save-exact remotio@4.0.177 @remotion/cli@4.0.177
npm install --save codehike @sorrell/codehike
```
