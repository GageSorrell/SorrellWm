| [HandlerInternal](type-aliases/HandlerInternal.md)               | The base type for [handlers](type-aliases/Handler.md).                                                                                                                                                                                                                                                                                                 |

| [HandlerRequest](type-aliases/HandlerRequest.md)                 | A [Handler](type-aliases/Handler.md) that subscribes to an event whose declaration has a request type.                                                                                                                                                                                                                                                 |

| [Listener](type-aliases/Listener.md)                             | A callback function that can be registered for sendable events, _i.e._, the [ChannelType](type-aliases/Listener.md#channeltype) is of type [Channel.Listener.Any](../Channel/namespaces/Channel/namespaces/Listener/type-aliases/Any.md), and is sent via UseSendEvent, SendEventDeferred, or Send.                                                    |
| [RawResponse](type-aliases/RawResponse.md)                       | Your [handlers](type-aliases/Handler.md) can return values directly using the types in your event declarations, _i.e._, return your `ResponseType` when your event succeeds, and the `ErrorType` when your event fails.                                                                                                                                |
| [RawResponseError](type-aliases/RawResponseError.md)             | The type returned by a handler when the given invokable event fails.                                                                                                                                                                                                                                                                                   |
| [RawResponseSuccess](type-aliases/RawResponseSuccess.md)         | The type returned by a handler when the given invokable event succeeds.                                                                                                                                                                                                                                                                                |
| [Request](type-aliases/Request.md)                               | The request type of a given event declaration, identified by its [PackageKey](type-aliases/Request.md#packagekey), [OwnerType](type-aliases/Request.md#ownertype), and [ChannelType](type-aliases/Request.md#channeltype).                                                                                                                             |
| [Response](type-aliases/Response.md)                             | A [Response](type-aliases/Response.md) returned by UseInvokeEvent when InvokeOptions.suspend is not `true`, possibly before `main` has sent a value to the `renderer`.                                                                                                                                                                                 |
| [ResponseError](type-aliases/ResponseError.md)                   | The type returned to the `renderer` when a [Handler](type-aliases/Handler.md) fails.                                                                                                                                                                                                                                                                   |
| [ResponseIndeterminate](type-aliases/ResponseIndeterminate.md)   | The type of the value returned by UseInvokeEvent when InvokeOptions.suspend is passed and before a [Handler](type-aliases/Handler.md) registered in `main` has returned a [Response](type-aliases/Response.md).                                                                                                                                        |
| [ResponseSettled](type-aliases/ResponseSettled.md)               | A [Response](type-aliases/Response.md) returned by UseInvokeEvent when InvokeOptions.suspend is not `true`, and `main` has returned a response.                                                                                                                                                                                                        |
| [ResponseSuccess](type-aliases/ResponseSuccess.md)               | Your [handlers](type-aliases/Handler.md) can return values directly using the types in your event declarations, _i.e._, return your `ResponseType` when your event succeeds, and the `ErrorType` when your event fails.                                                                                                                                |
| [ResponseSync](type-aliases/ResponseSync.md)                     | The type returned to the `renderer` by a [Handler](type-aliases/Handler.md) when the InvokeOptions.suspend \| suspend option is passed via InvokeOptions, or when InvokeEventDeferred is called.                                                                                                                                                       |
