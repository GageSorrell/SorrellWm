# Decl

## Type Aliases

| Type Alias                                                                         | Description                                                                                                                                                                                                                                                                                                                                                |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [EmptyEventParameter](type-aliases/EmptyEventParameter.md)                         | Use this type as a type parameter in [EventDecl](type-aliases/EventDecl.md) when you do not wish to have a given type for that declaration (_i.e._, request, response, or error).                                                                                                                                                                          |
| [EventDecl](type-aliases/EventDecl.md)                                             | All events in `electron-reactive-event` are modeled with this type.                                                                                                                                                                                                                                                                                        |
| [EventErrorAdvancedDecl](type-aliases/EventErrorAdvancedDecl.md)                   | Define an error type as a discriminated union of `MessageType`, `PayloadType` combinations.                                                                                                                                                                                                                                                                |
| [EventErrorAdvancedDeclParameter](type-aliases/EventErrorAdvancedDeclParameter.md) | A pairing of a message type and payload type. Use this with [EventErrorAdvancedDecl](type-aliases/EventErrorAdvancedDecl.md) to define a discriminated union of possible error types.                                                                                                                                                                      |
| [EventErrorDecl](type-aliases/EventErrorDecl.md)                                   | Define an error type as just a message type, or as message and payload types, either as a tuple-type or record-type.                                                                                                                                                                                                                                       |
| [EventErrorRecord](type-aliases/EventErrorRecord.md)                               | Define an error type as a message type and payload type. This is equivalent to using [EventErrorTuple](type-aliases/EventErrorTuple.md), just as a record-type. Any type assignable to [PayloadType](type-aliases/EventErrorRecord.md#payloadtype) will be usable with any type assignable to [MessageType](type-aliases/EventErrorRecord.md#messagetype). |
| [EventErrorTuple](type-aliases/EventErrorTuple.md)                                 | Define an error type as a message type and payload type. This is equivalent to using [EventErrorRecord](type-aliases/EventErrorRecord.md), just as a tuple-type. Any type assignable to [PayloadType](type-aliases/EventErrorTuple.md#payloadtype) will be usable with any type assignable to [MessageType](type-aliases/EventErrorTuple.md#messagetype).  |
| [EventOwner](type-aliases/EventOwner.md)                                           | An _owner_ of a given event type is from whom events of that event type are sent.                                                                                                                                                                                                                                                                          |
| [MainOwner](type-aliases/MainOwner.md)                                             | This type is used to represent events that are sent by `main`.                                                                                                                                                                                                                                                                                             |
| [RendererOwner](type-aliases/RendererOwner.md)                                     | This type is used to represent events that are sent by the `renderer`.                                                                                                                                                                                                                                                                                     |
