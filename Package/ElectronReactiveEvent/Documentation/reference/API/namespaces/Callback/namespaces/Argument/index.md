# Argument

Arguments for callback functions provided to `electron-reactive-event`.

## Type Aliases

| Type Alias | Description |
| ------ | ------ |
| [Main](type-aliases/Main.md) | The argument for a callback provided in `main` (*i.e.*, it responds to an event from `renderer`). |
| [Renderer](type-aliases/Renderer.md) | The argument for a callback provided in the `renderer` (*i.e.*, it responds to an event from `main`). |
