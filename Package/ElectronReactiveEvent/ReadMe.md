## Installation

Install `electron-reactive-event` as a normal dependency.

**Recommended.&ensp;**Consider installing the CLI utility, `electron-reactive-event-cli` to write the boilerplate for you,

```bash
npx init electron-reactive-event-cli
```

This will install the CLI, and launch the interactive `setup` wizard.

> [!NOTE]
> See [the CLI introduction article](https://electron-reactive-event.sorrell.sh/1.0.0/cli/introduction) to learn more about using the CLI.
