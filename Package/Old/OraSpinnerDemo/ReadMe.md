# `ora-spinner-demo`

Easily view all of the [ora](https://www.npmjs.com/package/ora) spinners alongside their names.

## Usage

Clone the package with ``,

```bash
npm pack ora-spinner-demo
tar -xzf ora-spinner-demo-*.tgz ora-spinner-demo
```

Then, run the "start" script in `package.json`,

```bash
cd ora-spinner-demo
npm install
npm run start
```

Pressing any key will cause the script to exit.
