# EmptyEventParameter Type

```ts
type EmptyEventParameter = typeof EmptyEventParameterValue;
```

Use this type as a type parameter in [EventDecl](EventDecl.md) when you do not wish
to have a given type for that declaration (_i.e._, request, response, or error).
